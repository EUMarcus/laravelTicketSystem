# Setup Instructions - Kampay Ticket System

This guide will help you set up the Kampay Ticket System on your local machine or server.

---

## Prerequisites

Before you begin, ensure you have the following installed:

- **PHP 8.2+** with extensions: `pdo`, `pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`, `bcmath`
- **Composer** (PHP dependency manager)
- **MySQL 8.0+** (or MariaDB 10.3+)
- **Node.js 18+** and **npm** (for frontend assets)
- **Git** (to clone the repository)

---

## Step 1: Clone the Repository

```bash
git clone <repository-url>
cd KampayTicketSystem
```

---

## Step 2: Install PHP Dependencies

```bash
composer install
```

This will install all Laravel and PHP dependencies defined in `composer.json`.

---

## Step 3: Configure Environment

1. **Copy the environment file**:
   ```bash
   cp .env.example .env
   ```

2. **Generate application key**:
   ```bash
   php artisan key:generate
   ```

3. **Edit `.env` file** with your configuration:

   ```env
   APP_NAME="Kampay Ticket System"
   APP_ENV=local
   APP_KEY=base64:... (generated by key:generate)
   APP_DEBUG=true
   APP_URL=http://localhost

   # Database Configuration
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=kampay_ticket_system
   DB_USERNAME=root
   DB_PASSWORD=your_mysql_password

   # Supabase Configuration (for file storage)
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_KEY=your_anon_key
   SUPABASE_SERVICE_KEY=your_service_key
   SUPABASE_BUCKET=ticket-attachments

   # Session Configuration
   SESSION_DRIVER=database
   SESSION_LIFETIME=120
   ```

   **Important Notes**:
   - If your MySQL password contains special characters (like `#`), wrap it in quotes: `DB_PASSWORD="your#password"`
   - Comment out or remove `DB_URL` if you're using individual database settings
   - Supabase is optional but recommended for file storage

---

## Step 4: Create MySQL Database

### Option A: Using MySQL Workbench

1. Open MySQL Workbench
2. Connect to your MySQL server
3. Run this SQL:
   ```sql
   CREATE DATABASE kampay_ticket_system 
   CHARACTER SET utf8mb4 
   COLLATE utf8mb4_unicode_ci;
   ```

### Option B: Using Command Line

```bash
mysql -u root -p
```

Then run:
```sql
CREATE DATABASE kampay_ticket_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

### Option C: Using phpMyAdmin

1. Open phpMyAdmin
2. Click "New" to create a database
3. Name: `kampay_ticket_system`
4. Collation: `utf8mb4_unicode_ci`
5. Click "Create"

## Step 5: Run Database Migrations

This will create all necessary tables in your database:

```bash
php artisan migrate
```

You should see output like:
```
Migration table created successfully.
Migrating: 2024_01_01_000001_create_profiles_table
Migrated:  2024_01_01_000001_create_profiles_table
...
```

**Verify migrations**:
```bash
php artisan migrate:status
```

All migrations should show `[1] Ran`.

---

## Step 6: Seed the Database (Optional but Recommended)

Database seeders populate your database with sample data for testing.

### What Gets Seeded:

1. **Users** (`UserSeeder`):
   - Admin account: `makoy@gmail.com` / `password` (Employee role)
   - Test user: `test@example.com` / `password` (Citizen role)

2. **Tickets** (`TicketSeeder`):
   - 15 sample tickets/reports with various statuses and priorities

3. **Suggestions** (`SuggestionSeeder`):
   - 12 sample community suggestions

4. **Announcements** (`AnnouncementSeeder`):
   - 10 sample announcements

### Run All Seeders:

```bash
php artisan db:seed
```

This runs the `DatabaseSeeder` which calls all individual seeders.

### Run Individual Seeders:

```bash
# Seed only users
php artisan db:seed --class=UserSeeder

# Seed only tickets
php artisan db:seed --class=TicketSeeder

# Seed only suggestions
php artisan db:seed --class=SuggestionSeeder

# Seed only announcements
php artisan db:seed --class=AnnouncementSeeder
```

### Fresh Migration + Seeding:

If you want to start fresh (⚠️ **WARNING**: This deletes all data):

```bash
php artisan migrate:fresh --seed
```

This will:
1. Drop all tables
2. Re-run all migrations
3. Run all seeders

## Troubleshooting

### Issue: "Access denied for user"

**Solution**: Check your MySQL credentials in `.env`:
- Verify `DB_USERNAME` and `DB_PASSWORD`
- Ensure the user has permissions on the database
- Test connection in MySQL Workbench

### Issue: "Migration table not found"

**Solution**: Run migrations:
```bash
php artisan migrate
```

### Issue: "Class not found" or "Autoload error"

**Solution**: Regenerate autoload files:
```bash
composer dump-autoload
```

### Issue: "Config cache" errors

**Solution**: Clear config cache:
```bash
php artisan config:clear
php artisan cache:clear
```

### Issue: "Supabase not configured" warnings

**Solution**: 
- This is **optional** - the app works without Supabase
- Files will be stored locally if Supabase is not configured
- To use Supabase, add credentials to `.env`:
  ```env
  SUPABASE_URL=https://your-project.supabase.co
  SUPABASE_SERVICE_KEY=your_service_key
  SUPABASE_BUCKET=ticket-attachments
  ```

### Issue: "Port 8000 already in use"

**Solution**: Use a different port:
```bash
php artisan serve --port=8080
```

## Production Deployment

### 1. Update `.env` for Production:

```env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-domain.com

# Use production database
DB_CONNECTION=mysql
DB_HOST=your-production-host
DB_DATABASE=your_production_db
DB_USERNAME=your_production_user
DB_PASSWORD=your_production_password
```

### 2. Optimize for Production:

```bash
# Cache configuration
php artisan config:cache

# Cache routes
php artisan route:cache

# Cache views
php artisan view:cache

# Build assets
npm run build
```

### 3. Set Proper Permissions:

```bash
chmod -R 755 storage bootstrap/cache
```

### 4. Run Migrations:

```bash
php artisan migrate --force
```
